# ServiceDesk 360

Sistema web para la gestión de solicitudes de soporte técnico, desarrollado como parte de la asignatura de Desarrollo de Aplicaciones Multiplataforma.

## 📋 Descripción

ServiceDesk 360 permite gestionar solicitudes de soporte técnico, facilitando el registro, seguimiento y administración de incidencias.

El proyecto fue desarrollado utilizando Java, JSP y Servlets, siguiendo una arquitectura orientada a aplicaciones web Java.

## 🛠️ Tecnologías utilizadas

- Java JDK 11+
- JSP
- Servlets
- Apache Tomcat 9
- Apache Maven
- Apache NetBeans
- HTML5
- CSS3
- MySQL <!-- si utilizaste MySQL -->

## ⚙️ Requisitos

Antes de ejecutar el proyecto necesitas tener instalado:

1. Java JDK 11 o superior.
2. Apache NetBeans.
3. Apache Tomcat 9.
4. Apache Maven.
5. Base de datos MySQL <!-- si aplica -->.
